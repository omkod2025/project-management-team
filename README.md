# บ้านน่าอยู่ — Resident App Prototype

เว็บแอปลูกบ้านสำหรับนำเสนอขาย อ้างอิง `resident-user-manual.html` และวิดีโอใน `references/` เสริมขั้นตอนที่ขาดด้วยสถานการณ์จำลองตามที่ตกลง

## เปิดใช้งาน

```powershell
npm start
```

เปิด **http://localhost:4173** (Node.js 18 ขึ้นไป) ไม่ต้องติดตั้ง dependency สำหรับรันแอป และเปิด `index.html` โดยตรงได้ด้วย แต่แนะนำ HTTP เพื่อให้ localStorage และดาวน์โหลดทำงานสม่ำเสมอ

- Layout แอปลูกบ้านกว้างสูงสุด 460px; หน้าสภาพอากาศขยายถึง 760px บนเดสก์ท็อป
- ภาษาเริ่มต้นเป็นไทย มีตัวเลือกภาษาอังกฤษสำหรับเมนูหลักและข้อความนำทางบางส่วน
- ฟอนต์และภาพประกอบอยู่ในโปรเจกต์ ใช้งานโดยไม่เรียกทรัพยากรภายนอก
- หน้าสภาพอากาศเรียก Open-Meteo โดยตรงจากเบราว์เซอร์; ส่วนบัญชีและธุรกรรมเป็นการจำลอง
- ข้อมูลเก็บใน localStorage ชื่อ `bannayuu.resident.v1` ของ origin/เบราว์เซอร์นี้

## Build สำหรับนำไปใช้งาน

```powershell
npm run build
```

ตรวจ syntax ของ JavaScript และสร้างไฟล์พร้อมใช้งานใน `dist/` รวมหน้าแอป ฟอนต์ ภาพ คู่มือ และวิดีโออ้างอิง เพื่อให้ลิงก์ในคู่มือยังเปิดได้ เสิร์ฟโฟลเดอร์ `dist/` ผ่าน Nginx หรือ static hosting ได้เลย หน้า Weather เรียก Open-Meteo โดยตรง ไม่ต้องรัน Node backend หรือ proxy `/api/environment` หากโฮสต์กำหนด Content-Security-Policy ให้ `connect-src` อนุญาต `https://api.open-meteo.com` และ `https://air-quality-api.open-meteo.com` ด้วย สำหรับการเปิดในเครื่องยังใช้ `node dist/server.cjs` ได้

การ build แต่ละครั้งจะสร้าง `dist/` ใหม่ โค้ดต้นฉบับและข้อมูล localStorage ในเบราว์เซอร์ไม่ได้รับผลกระทบ

## เส้นทางนำเสนอแนะนำ

1. หน้าหลัก: บ้าน 212/1, ยอดบิล 2,500 บาท และพัสดุรอรับ 2 ชิ้น
2. ชำระบิล → ยืนยันชำระเงินจำลอง → ดาวน์โหลดใบเสร็จ HTML
3. พัสดุ → รับพัสดุ → ตรวจประวัติ
4. จองส่วนกลาง → เลือกวัน/เวลา → ตรวจการจอง หรือยกเลิก
5. ห้องของฉัน → ดูรหัสเชิญ → จำลองสมาชิกเข้าร่วม → แก้ไขบทบาท
6. ยานพาหนะ → กรอกข้อมูล 3 ขั้นตอน → ลงทะเบียนสำเร็จ
7. สัตว์เลี้ยง → เลือกแบบบัตร/แนบรูป → สร้าง Pet Card → บันทึก PNG
8. ผู้มาติดต่อ → ลงทะเบียน → i-Pass → สลับด้าน/ดาวน์โหลด → จำลอง E-Stamp
9. บริการ → จองล้างแอร์ → ดูรายการจอง
10. ไทม์ไลน์ → โพสต์ → ถูกใจ/ความคิดเห็น
11. ช้อปปิ้ง → KUMA → เพิ่มลงรถเข็น → **เลือกสินค้า** → สั่งซื้อจำลอง
12. ตั้งค่า → โหมดนำเสนอ → รีเซ็ตข้อมูล เพื่อเริ่มใหม่

## ขอบเขตการจำลอง

- เริ่มจากผู้ใช้ที่เข้าสู่ระบบและผูกบ้านแล้ว ตามจุดเริ่มต้นในคู่มือ ไม่มี login จริง
- การจ่ายเงิน โทร แชท โพสต์ จอง ลงคะแนน แลกรับ และสั่งซื้อ ไม่ติดต่อบุคคลหรือบริการจริง
- QR ในบัตรเป็นลายตัวอย่างติดป้าย DEMO **ไม่ใช่ QR ที่ใช้สแกนเข้าพื้นที่จริง** การสแกน E-Stamp ใช้เลือกบัตรแล้วจำลองผล
- ลิงก์ i-Pass อ้างอิงข้อมูลในเบราว์เซอร์เดิม ไม่ทำงานข้ามอุปกรณ์
- ข้อมูลรถ/บิล/พัสดุ/ผู้มาติดต่อ/งานแจ้งซ่อม/การจอง/คำสั่งซื้อแยกตามบ้าน สัตว์เลี้ยงและโปรไฟล์เป็นของผู้ใช้
- การตั้งค่า “แสดงหน้าว่างตามวิดีโอ” ซ่อนข้อมูลตัวอย่างในบางหมวดโดยไม่ลบข้อมูลที่เก็บไว้
- รูป PNG/JPG สูงสุด 5 MB ต่อรูป จะย่อด้านยาวเหลือไม่เกิน 700px ก่อนจัดเก็บ หากพื้นที่เต็มระบบแจ้งเตือนและไม่ยืนยันว่าบันทึกสำเร็จ
- ราคา โฆษณา และเนื้อหาที่ขาดจากคู่มือใช้ข้อมูลสมมติ ภาพประกอบสร้างเป็น SVG ไม่ใช้โฆษณาหรือรหัสบุคคลจากวิดีโอ
- การเลือกภาษาอังกฤษเป็นการสาธิตบางส่วน ไม่ใช่การแปลทั้งแอป

## ตรวจสอบ

```powershell
npm test
```

ใช้ Playwright ที่ติดตั้งในเครื่อง (หรือตำแหน่ง runtime ของ workspace นี้) ทดสอบ flow หลัก, persistence, isolation ของบ้าน, validation, downloads และหน้าจอขนาด 320/390/1440px ผลอยู่ใน `.work/app/verification.json` และ screenshots ใน `.work/app/`

ทดสอบกรณีข้อมูลไม่ถูกต้อง รูปภาพ ข้อมูลรถ ปุ่มย้อนกลับ และพื้นที่จัดเก็บเต็มเพิ่มเติมด้วย `node tests/edge.cjs` ขณะเปิด `npm start` อยู่ ผลอยู่ใน `.work/app/edge-verification.json`.

ไฟล์หลัก: `index.html`, `app.js`, `styles.css`, `typography.css`, `assets/`, `server.cjs`.

## สภาพอากาศและฝุ่น

กด “สภาพอากาศและฝุ่น” ในหน้าแรก หรือเปิด `/#weather` หลังรัน `npm start` (หาก server เปิดอยู่ก่อนแก้ไข ต้องเริ่มใหม่เพื่อโหลด endpoint ใหม่)

- ภาษาไทย เวลา Asia/Bangkok พื้นที่กรุงเทพฯ; กราฟอุณหภูมิ/โอกาสฝน/ลม และพยากรณ์ 8 วัน
- US AQI ภาพรวม, PM2.5, PM10 และระดับดัชนีเฉพาะ PM2.5 แยกจากค่าความเข้มข้น
- `GET /api/environment` รวม Open-Meteo Weather และ Air Quality แบบขนาน แยก cache 15 นาที, timeout 10 วินาที, retry network/5xx หนึ่งครั้ง, เคารพ Retry-After, fallback ข้อมูลเก่าไม่เกิน 60 นาที
- Cache อยู่ในหน่วยความจำของ process; การ restart จะล้าง cache ข้อมูลฝุ่นเป็นแบบจำลอง CAMS
- ตรวจสอบ: `node tests/environment.cjs`; UI: เปิด server พอร์ต 4174 แล้วรัน `node tests/weather.cjs` (ใช้ข้อมูล fixture แยกจาก API จริง)
- แหล่งข้อมูล: https://open-meteo.com/en/docs และ https://open-meteo.com/en/docs/air-quality-api การใช้เชิงพาณิชย์ต้องเลือกแพ็กเกจที่รองรับตามเงื่อนไขผู้ให้บริการ
