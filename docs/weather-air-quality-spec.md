# Spec: คุณภาพอากาศและฝุ่น — หน้า Weather

วันที่ตรวจสอบ: 24 กันยายน 2026 · Route: `/#weather` · Implementation: `weather.js`

## 1. แหล่งข้อมูลและขอบเขต

เบราว์เซอร์เรียก Open-Meteo Air Quality API โดยตรงผ่าน HTTPS ไม่ต้องมี backend ของแอป ข้อมูลมาจากแบบจำลอง CAMS จึงเป็นค่าประมาณของพื้นที่ ไม่ใช่ค่าจากเครื่องวัดฝุ่นที่ติดตั้งในบ้านหรือโครงการ [เอกสาร Open-Meteo](https://open-meteo.com/en/docs/air-quality-api)

- Endpoint: `https://air-quality-api.open-meteo.com/v1/air-quality`
- พิกัดปัจจุบัน: กรุงเทพมหานคร `latitude=13.7563`, `longitude=100.5018` เป็นค่าคงที่ ยังไม่ได้เปลี่ยนตามบ้านที่เลือกหรือ GPS
- เขตเวลา: `Asia/Bangkok` (UTC+7)
- พารามิเตอร์: `current=us_aqi,us_aqi_pm2_5,pm2_5,pm10`
- ใช้เกณฑ์ **US AQI** สำหรับการจัดระดับ ไม่ใช่เกณฑ์ AQI ของประเทศไทย
- แอปใช้ดัชนีที่ผู้ให้บริการคำนวณแล้ว ไม่คำนวณ AQI ใหม่จากความเข้มข้นฝุ่น

## 2. ข้อมูลที่แสดง

| ส่วนใน UI | ฟิลด์ API → ฟิลด์ในแอป | ความหมาย / หน่วย | วิธีแสดงสถานะ |
|---|---|---|---|
| คุณภาพอากาศปัจจุบัน | `us_aqi` → `usAqi` | ดัชนีคุณภาพอากาศภาพรวม ไม่มีหน่วย | ใช้ตาราง US AQI ด้านล่าง |
| ปริมาณ PM2.5 | `pm2_5` → `pm25UgM3` | ความเข้มข้นฝุ่นขนาดไม่เกิน 2.5 ไมครอน หน่วย µg/m³ | แสดงตัวเลขทศนิยมไม่เกิน 1 ตำแหน่ง |
| สถานะของ PM2.5 | `us_aqi_pm2_5` → `pm25Aqi` | ดัชนี US AQI เฉพาะ PM2.5 ไม่มีหน่วย | ใช้ตารางเดียวกัน และแสดงข้อความ “ดัชนีเฉพาะ PM2.5” |
| ปริมาณ PM10 | `pm10` → `pm10UgM3` | ความเข้มข้นฝุ่นขนาดไม่เกิน 10 ไมครอน หน่วย µg/m³ | แสดงตัวเลขทศนิยมไม่เกิน 1 ตำแหน่ง ปัจจุบันไม่มีสถานะ AQI เฉพาะ PM10 |

**ห้ามนำค่า PM2.5 หรือ PM10 ที่มีหน่วย µg/m³ ไปเทียบตาราง AQI โดยตรง** ตัวเลขเหมือนกันอาจมีความหมายต่างกัน และสถานะภาพรวมไม่จำเป็นต้องตรงกับสถานะ PM2.5

## 3. ตาราง US AQI → ข้อความและสี

ช่วงจำนวนเต็มอ้างอิง [AirNow / U.S. EPA: AQI Basics](https://www.airnow.gov/aqi/aqi-basics/) ข้อความภาษาไทยและรหัสสีด้านล่างตรงกับแอปปัจจุบัน

| ค่า US AQI | ข้อความในแอป | สี | ตัวอย่าง |
|---|---|---|---|
| 0–50 | คุณภาพอากาศดี | เขียว `#00E400` | 32 → คุณภาพอากาศดี |
| 51–100 | คุณภาพอากาศปานกลาง | เหลือง `#FFFF00` | **73 → คุณภาพอากาศปานกลาง** |
| 101–150 | มีผลต่อสุขภาพของกลุ่มเสี่ยง | ส้ม `#FF7E00` | 125 → มีผลต่อสุขภาพของกลุ่มเสี่ยง |
| 151–200 | มีผลต่อสุขภาพ | แดง `#FF0000` | 173 → มีผลต่อสุขภาพ |
| 201–300 | มีผลต่อสุขภาพอย่างมาก | ม่วง `#8F3F97` | 250 → มีผลต่อสุขภาพอย่างมาก |
| ตั้งแต่ 301 | อันตราย | แดงเลือดหมู `#7E0023` | 350 → อันตราย |
| ค่าดัชนีไม่ถูกต้อง / ไม่มีค่า | ไม่มีข้อมูล | เทา `#6B7280` | `null`, ค่าติดลบ, `NaN`, `Infinity` |

เกณฑ์ในโค้ดรองรับทศนิยมโดยใช้ค่าดิบ: `0 ≤ n ≤ 50`, `50 < n ≤ 100`, `100 < n ≤ 150`, `150 < n ≤ 200`, `200 < n ≤ 300`, `n > 300` ไม่ปัดก่อนเลือกสถานะ

ข้อจำกัดปัจจุบัน: ตัวเลข AQI บนจอปัดเป็นจำนวนเต็ม แต่สถานะใช้ค่าดิบ เช่น `50.1` แสดงเลข `50` แต่สถานะปานกลาง ต้องรับรู้ความต่างนี้เมื่อทดสอบบริเวณรอยต่อ การปรับกฎปัดเศษต้องแก้ทั้ง spec และโค้ดพร้อมกัน

## 4. ตัวอย่างการอ่านค่า

ตัวอย่างต่อไปนี้เป็นข้อมูลประกอบ spec ไม่ใช่ค่าตรวจวัดจริง และไม่ใช่สูตรแปลง PM เป็น AQI

| ค่าที่ API ส่งมา | ผลลัพธ์ |
|---|---|
| `us_aqi = 73` | ภาพรวม: 73 US AQI / คุณภาพอากาศปานกลาง / สีเหลือง |
| `us_aqi_pm2_5 = 73` | สถานะ PM2.5: คุณภาพอากาศปานกลาง / ดัชนีเฉพาะ PM2.5: 73 |
| `pm2_5 = 73` | ปริมาณ PM2.5: 73 µg/m³; ต้องอ่าน `us_aqi_pm2_5` เพื่อระบุสถานะ ห้ามสรุปว่าปานกลางจากเลข 73 นี้ |
| `pm10 = 73` | ปริมาณ PM10: 73 µg/m³; ไม่มีการจัดสี AQI ของ PM10 ในแอปปัจจุบัน |
| `us_aqi = 125`, `us_aqi_pm2_5 = 73` | ภาพรวมเป็นสีส้ม แต่สถานะ PM2.5 เป็นสีเหลือง ใช้คนละฟิลด์ |
| `pm2_5 = 0` | แสดง 0 µg/m³ ไม่ถือเป็นข้อมูลหาย |

## 5. การอัปเดตและสถานะข้อผิดพลาด

- แคชข้อมูลที่โหลดสำเร็จในหน่วยความจำเบราว์เซอร์ 15 นาที; รีโหลดหน้าเว็บจะล้างแคชนี้
- ตรวจอัปเดตทุก 15 นาทีเมื่อหน้าเว็บมองเห็น และเมื่อกลับมาเปิดแท็บ โดยใช้แคชหากยังไม่หมดอายุ
- แสดงเวลาข้อมูลจาก `current.time` แยกจากเวลาดึงข้อมูล `fetchedAt` การดึงทุก 15 นาทีไม่ได้แปลว่าแบบจำลองมีข้อมูลใหม่ทุก 15 นาที
- หากโหลดใหม่ไม่สำเร็จและมีข้อมูลเดิมอายุไม่เกิน 60 นาที แสดงข้อมูลเดิมพร้อม “ข้อมูลเก่า · โหลดข้อมูลล่าสุดไม่สำเร็จ”
- หากไม่มีข้อมูลเดิมที่ใช้ได้ แสดงสถานะไม่มีข้อมูลและปุ่ม “ลองใหม่”; ห้ามแทนค่าที่หายด้วย 0 หรือสถานะอากาศดี
- ตัวเลขที่ไม่ใช่ finite number แสดง `—`; หากไม่มีดัชนี AQI ที่ถูกต้อง ให้สถานะ “ไม่มีข้อมูล”
- อากาศและคุณภาพอากาศเรียกคนละ endpoint; ส่วนหนึ่งล้มเหลวไม่ทำให้ข้อมูลอีกส่วนหาย
- เมื่อ API ตอบ 429 ให้รอตาม `Retry-After` ที่อ่านได้ หรือ 15 นาทีหากอ่านไม่ได้
- คงข้อความอ้างอิง Open-Meteo / CAMS และข้อความอธิบายว่าเป็นค่าประมาณจากแบบจำลองไว้บนหน้า

## 6. Acceptance criteria

1. AQI 73 แสดง “คุณภาพอากาศปานกลาง” และจุดสีเหลือง
2. ตรวจขอบช่วงด้วย 0, 50, 51, 100, 101, 150, 151, 200, 201, 300, 301 ให้ตรงตาราง
3. ตรวจทศนิยม 50.1 และ 100.1 ตามเงื่อนไขค่าดิบที่ระบุไว้
4. `null`, ค่าดัชนีติดลบ และค่าที่ไม่ใช่ตัวเลข แสดง “ไม่มีข้อมูล” ไม่เป็นสีเขียว
5. ค่า PM2.5 73 µg/m³ ไม่ถูกใช้แทน AQI 73; สถานะต้องอิง `us_aqi_pm2_5`
6. PM10 แสดงหน่วย µg/m³ โดยไม่เพิ่มระดับสุขภาพที่ไม่ได้คำนวณ
7. เวลาแสดงเป็นกรุงเทพฯ แม้ timezone ของอุปกรณ์เป็นประเทศอื่น
8. โหลดคุณภาพอากาศล้มเหลวแล้วส่วนสภาพอากาศยังแสดงได้ และมีปุ่มลองใหม่
