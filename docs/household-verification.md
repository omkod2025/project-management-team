# การยืนยันบัตรประชาชนก่อนเข้า

หน้าห้องของฉันมีการตั้งค่า `contactPolicy.requireIdVerification` แยกต่อบ้าน ค่าเริ่มต้นเป็น `true` ทั้งบ้านใหม่และข้อมูลเก่าที่ยังไม่มีค่า โดยค่า `false` ที่เจ้าบ้านเลือกไว้จะไม่ถูกเปลี่ยนกลับ

เฉพาะสมาชิกบทบาท `เจ้าบ้าน` เปลี่ยนค่าได้ สมาชิกอื่นเห็นข้อความสถานะแบบอ่านอย่างเดียว และฟังก์ชันบันทึกตรวจบทบาทอีกครั้ง การเปลี่ยนค่าไม่เปลี่ยนโหมดผู้มาติดต่อ ผู้รับสายอนุมัติ หรือสิทธิ์ E-Stamp

หน้าสรุปรวมค่าการเข้า–ออกไว้ในกลุ่มเดียว รายชื่อสมาชิกยุบเริ่มต้น เจ้าบ้านแตะแถวโหมดหรือผู้รับสายเพื่อเปิดหน้าแก้ไขแยก (`#household/mode` และ `#household/recipient`) การเปลี่ยนผู้รับสายยังมีระยะรอ 60 นาที และเปิดแก้ไขได้เฉพาะโหมดขออนุมัติ

นี่คือการตั้งค่าในต้นแบบ ยังไม่ได้เชื่อมบริการตรวจบัตรประชาชนหรืออุปกรณ์เปิดประตู ระบบจริงต้องตรวจสิทธิ์เจ้าบ้านฝั่งเซิร์ฟเวอร์ และบังคับผลยืนยันบัตรผ่านก่อนอนุญาตเข้าเมื่อเปิดตัวเลือกนี้ โหมดห้ามรบกวนยังคงปฏิเสธการเข้าเสมอ
