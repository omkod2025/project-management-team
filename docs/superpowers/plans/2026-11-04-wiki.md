# Wiki (คลังความรู้) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A top-level knowledge base, not tied to any project. Wikis are shared per wiki (read or write), can have a whole-wiki public link, and are read by AI only through a read-only MCP endpoint authenticated by personal access tokens that each user scopes to particular wikis.

**Architecture:** New `pmt_wiki*` tables, never shared with Docs. All decisions live in the pure module `src/lib/wiki-rules.ts` (visibility, token effectiveness, search terms, rate limit). The adapters are `wiki.ts`, `wiki-tokens.ts`, `wiki-assets.ts`, `wiki-asset-cleanup.ts`, `wiki-publish.ts` and `wiki-mcp.ts`. The editor UI reuses the Docs `PageEditor`/`RichEditor`/`DocContent` through a new `DocEndpoints` prop, so nothing is copied.

**Tech Stack:** Next.js (read `node_modules/next/dist/docs/` before writing routes), PostgreSQL 18 with `pg_trgm`, Drizzle, TipTap, `@modelcontextprotocol/sdk` (new), node:test.

**Spec:** `docs/superpowers/specs/2026-11-04-wiki-design.md`. **Depends on:** `2026-11-04-mermaid-blocks.md`, which must be finished first.

## Global Constraints

- Naming follows CLAUDE.md: `pmt_`/`pmf_`/`pmp_`, the entity prefix on every column, no reserved words, and enum types end in `_kind`. No triggers.
- Every refusal a non-member could see is a bare 404 (`E_NOT_FOUND`), the same on app routes, asset routes and public routes. MCP tools answer "not found" for anything outside scope, and any bad token gets 401.
- Every user, editor, import, token or MCP value is a bound parameter. **No such value ever reaches `sql.raw`.** `LIKE` wildcards (`\`, `%`, `_`) are escaped in the bound value.
- The install admin is `PROTECTED_EMAIL` (`admin@cit.com`, `src/lib/admin-rules.ts:332`) while active. Project admin roles grant nothing in the Wiki.
- Page depth is 1–3. Slugs are set once and unique per wiki. A page body holds up to 200,000 characters (reuse the Docs limit). Mermaid holds up to 50,000 characters per block (`assertMermaidLimits`).
- Token secret: `pmw_` + 32 random bytes as base64url (43 characters). Store `sha256` hex and the first 8 characters after `pmw_` as the prefix. Show the secret once. At most 20 active tokens per user. Optional expiry.
- The effective wikis of a token are `scopes ∩ wikis its owner can see right now`, and the token gets nothing if it is revoked, expired, or its owner is inactive or deleted.
- The MCP endpoint is `POST /api/mcp`, Bearer only, cookies ignored. Wiki REST routes are session only, so a Bearer header alone gets 401. Rate limit: 60 requests per minute per token.
- Public link: 32 random bytes as base64url on `pmt_wikis.wiki_public_token`. `noindex,nofollow`, `Cache-Control: no-store`, links back into the app are removed, and assets are served only if a non-archived page of that wiki references them. Archiving the wiki withdraws the link. The link grants nothing over MCP.
- UI follows DESIGN.md: square corners, no cards, no shadows, no vermilion. Chrome is in English and content is Thai. No `letter-spacing` or uppercase on Thai.
- Tested pure modules import with explicit `.ts` extensions and use no constructor parameter properties.

## Review Focus

1. **A membership change while a token or a page is open.** After removal, the next MCP call and the next page load both return not-found. Test `token loses a wiki the moment its owner loses membership` (Task 10), and `removed member gets 404 on next read` (Task 4).
2. **Thai mid-word search** (`ปลั๊ก` inside `เปลี่ยนปลั๊กไฟ`) and queries made of wildcards only (`%`, `_`, `\`). They must match only literally. Tests in Task 6.
3. **Deleting the owner's account.** The wiki must move to the install admin in the same transaction, and the owner's tokens must stop. Task 4 test `deleting the owner hands the wiki to the install admin`.
4. **A public page linking to another page of the same wiki** (`/wiki/<id>/<slug>`). It must be rewritten to `/w/<token>/<slug>`. Links to other wikis or projects are removed. Task 8 test.
5. **A revoked token used for a call already in flight, or an old token after it was regenerated.** It must get 401, and `last_used_at` must not be touched. Task 10 test.
