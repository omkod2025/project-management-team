# เข้าสู่ระบบ

- ชื่อผู้ใช้: `cit`
- รหัสผ่าน: `cit12345`
- Session เก็บใน localStorage ชื่อ `bannayuu.session.v1` และหมดอายุ 24 ชั่วโมงนับจากเข้าสู่ระบบสำเร็จ ไม่มีการต่ออายุเมื่อรีเฟรชหรือใช้งาน
- ปิดและเปิดเบราว์เซอร์ใหม่ภายใน 24 ชั่วโมงยังใช้งานได้ หากไม่ได้ล้างข้อมูลเว็บไซต์
- ออกจากระบบได้ในหน้าตั้งค่า โดยออกจากระบบในแท็บอื่นของเว็บไซต์เดียวกันด้วย ข้อมูลสาธิตของแอปยังคงอยู่
- ทดสอบด้วย `node tests/login.cjs`

นี่คือ Login สำหรับ static prototype: การตรวจบัญชีและ session ทำในเบราว์เซอร์ จึงไม่ใช่การป้องกันข้อมูลสำหรับระบบใช้งานจริง หากนำไปใช้กับข้อมูลจริงต้องเพิ่มการยืนยันตัวตนและตรวจ session ฝั่งเซิร์ฟเวอร์
