# Spec: สภาพอากาศ ฝน และอุณหภูมิ

วันที่ตรวจสอบ: 24 กันยายน 2026 · Route: `/#weather` · Implementation: `weather.js`

เอกสารนี้ระบุพฤติกรรมที่มีอยู่จริง ส่วนเกณฑ์ “อากาศร้อน” เป็นเกณฑ์อ้างอิงสำหรับเพิ่มในอนาคต ยังไม่ได้แสดงสถานะดังกล่าวใน UI ปัจจุบัน

## 1. แหล่งข้อมูลและหลักการ

เรียก `https://api.open-meteo.com/v1/forecast` จากเบราว์เซอร์ พิกัดคงที่กรุงเทพฯ `13.7563, 100.5018` เขตเวลา `Asia/Bangkok` ข้อมูลเป็นผลแบบจำลอง ไม่ใช่เซนเซอร์ประจำบ้าน

สถานะ “ฝนหนัก / มีเมฆ / ท้องฟ้าแจ่มใส” อ่านจาก `weather_code` ตามตาราง WMO ที่ Open-Meteo ส่งมา ไม่ได้ตัดสินจากอุณหภูมิ ความชื้น หรือเปอร์เซ็นต์โอกาสฝนตก [เอกสาร Open-Meteo](https://open-meteo.com/en/docs)

## 2. รหัสสภาพอากาศ → ข้อความและไอคอน

ตารางนี้คือ mapping ใน `condition(code, isDay)` ของแอป อิงรหัสจาก Open-Meteo โดยบางรหัสรวมเป็นข้อความไทยเดียวกัน

| `weather_code` | ข้อความในแอป | ไอคอน |
|---|---|---|
| 0 | ท้องฟ้าแจ่มใส | ☀️ กลางวัน / 🌙 กลางคืน |
| 1 | มีเมฆเล็กน้อย | 🌤️ กลางวัน / ☁️ กลางคืน |
| 2 | มีเมฆบางส่วน | 🌤️ กลางวัน / ☁️ กลางคืน |
| 3 | มีเมฆมาก | ☁️ |
| 45, 48 | มีหมอก | 🌫️ |
| 51, 53, 55 | ฝนปรอย | 🌦️ |
| 56, 57, 66, 67 | ฝนเยือกแข็ง | 🌨️ |
| 61 | ฝนเล็กน้อย | 🌧️ |
| 63 | ฝนปานกลาง | 🌧️ |
| 65 | ฝนหนัก | 🌧️ |
| 71, 73, 75, 77, 85, 86 | หิมะตก | 🌨️ |
| 80, 81, 82 | ฝนตกเป็นช่วง ๆ | 🌧️ |
| 95 | ฝนฟ้าคะนอง | ⛈️ |
| 96, 99 | ฝนฟ้าคะนองและลูกเห็บ | ⛈️ |
| `null` หรือรหัสอื่นที่ไม่รองรับ | ไม่มีข้อมูล | — |

`current.is_day = 1` หมายถึงกลางวัน, `0` หมายถึงกลางคืน ใช้เปลี่ยนไอคอนเฉพาะรหัส 0–2; หากค่าไม่ครบ โค้ดปัจจุบันใช้รูปแบบกลางวันเป็นค่าเริ่มต้น

รหัส 56/57 และ 66/67 เป็นคนละกลุ่มฝนเยือกแข็งในแหล่งข้อมูล แต่ UI ปัจจุบันย่อข้อความเหมือนกัน เช่นเดียวกับกลุ่มหิมะและฝนตกเป็นช่วง ๆ การรองรับรหัสทั้งหมดไม่ได้หมายความว่าจะเกิดทุกสภาพในกรุงเทพฯ

## 3. โอกาสฝนตก (%)

- ใช้ `hourly.precipitation_probability` หน่วยเปอร์เซ็นต์ แยกจาก `weather_code`
- Open-Meteo นิยามเป็นโอกาสเกิดหยาดน้ำฟ้ามากกว่า 0.1 มม. ในช่วงชั่วโมงก่อน timestamp ของข้อมูล [นิยามตัวแปร](https://open-meteo.com/en/docs#hourly-parameter-definition)
- ค่า 73% หมายถึงความน่าจะเป็นของเหตุการณ์ในช่วงเวลานั้น ไม่ใช่ฝนตก 73% ของพื้นที่ ไม่ใช่ปริมาณฝน 73 มม. และไม่ใช่ความแรงของฝน
- แอปไม่มีการแบ่งเปอร์เซ็นต์เป็นระดับ “น้อย / ปานกลาง / มาก” และไม่ใช้เกณฑ์ เช่น ≥50% เพื่อเปลี่ยนสถานะเป็น “ฝนตก”
- 0% เป็นค่าที่แสดงได้ ไม่ใช่ข้อมูลหาย; หากไม่พบข้อมูลให้แสดง `—`
- ข้อความใน UI ปัจจุบันคือ “โอกาสฝนตกชั่วโมงนี้” โดยเลือก hourly timestamp ที่มีวันและชั่วโมงตรงกับ `current.time` เช่น 10:15 ใช้รายการ 10:00 ไม่ใช่การคำนวณโอกาสใน 60 นาทีถัดไป
- ข้อจำกัดด้านข้อความ: ชื่อ “ชั่วโมงนี้” อาจทำให้เข้าใจต่างจากช่วงเวลาสะสมของ API ควรปรับเป็น “โอกาสฝนตก · ข้อมูลเวลา HH:00” ในงานปรับ UI ครั้งถัดไป

ตัวอย่าง: `weather_code=3` และ `precipitation_probability=73` แสดง “มีเมฆมาก” พร้อมโอกาสฝนตก 73% ไม่เปลี่ยนเป็น “ฝนหนัก”

## 4. อุณหภูมิและเกณฑ์อากาศร้อน

### พฤติกรรมปัจจุบัน

- อุณหภูมิปัจจุบันใช้ `current.temperature_2m` หน่วย °C
- กราฟใช้ `hourly.temperature_2m`; ค่าสูงสุด/ต่ำสุดแต่ละวันใช้ `daily.temperature_2m_max` และ `daily.temperature_2m_min`
- **ยังไม่มีการจัดสถานะ “อากาศร้อน / ร้อนจัด / เย็น / หนาว” ในโค้ด** เช่น 36°C ยังแสดงสถานะจาก `weather_code` เท่านั้น
- ไอคอนดวงอาทิตย์หมายถึงท้องฟ้าแจ่มใส ไม่ได้หมายความว่าอุณหภูมิถึงเกณฑ์ร้อน
- ยังไม่ได้เรียก apparent temperature หรือคำนวณ Heat Index จึงห้ามเรียกตัวเลขอุณหภูมินี้ว่า “รู้สึกเหมือน” หรือ “ดัชนีความร้อน”

### เกณฑ์อ้างอิงสำหรับเพิ่มสถานะร้อน — ยังไม่ implement

กรมอุตุนิยมวิทยากำหนดเกณฑ์อากาศร้อนโดยใช้อุณหภูมิสูงสุดประจำวันและใช้ในฤดูร้อน ไม่ใช่การจำแนกจากอุณหภูมิปัจจุบันทุกช่วงเวลา [เกณฑ์อากาศร้อน กรมอุตุนิยมวิทยา](https://www.tmd.go.th/info/เกณฑ์อากาศร้อน), [คำอธิบายอุณหภูมิ](https://tmd.go.th/info/อณหภม)

| อุณหภูมิสูงสุดประจำวัน | เกณฑ์อ้างอิง | ตัวอย่าง |
|---|---|---|
| ต่ำกว่า 35.0°C | ไม่ถึงเกณฑ์ “อากาศร้อน” นี้; ไม่ได้แปลว่าเย็นหรือหนาว | 34.9°C |
| 35.0–39.9°C | อากาศร้อน | 36.5°C → อากาศร้อน |
| ตั้งแต่ 40.0°C | อากาศร้อนจัด | 40.0°C → อากาศร้อนจัด |

หากนำไปเพิ่มในผลิตภัณฑ์ ให้ใช้ `daily.temperature_2m_max` และระบุว่าเป็น “คาดการณ์อุณหภูมิสูงสุด” แสดงแยกจากสถานะฝน/เมฆ โดยไม่แทนที่กัน เช่น วันเดียวกันอาจคาดว่าร้อนและมีฝนฟ้าคะนองได้ การใช้ค่าปัจจุบันเพื่อแจ้ง “ร้อนตอนนี้” ต้องกำหนดกติกาผลิตภัณฑ์แยก ไม่อ้างว่าเป็นเกณฑ์รายวันของกรมฯ

## 5. ความชื้น ลม และพยากรณ์

| รายการ | แหล่งข้อมูล | วิธีแสดงในแอป |
|---|---|---|
| ความชื้นสัมพัทธ์ | `current.relative_humidity_2m` | % ไม่มีการจัดระดับ; ความชื้นสูงไม่เท่ากับฝนกำลังตก |
| ความเร็วลม | `current.wind_speed_10m` | km/h ทศนิยมไม่เกิน 1 ตำแหน่ง; ไม่ใช่ความเร็วลมกระโชก |
| กราฟลม | `hourly.wind_speed_10m` | km/h; ยังไม่แบ่งระดับตามมาตราโบฟอร์ต |
| สภาพอากาศรายวัน | `daily.weather_code` | ใช้ mapping เดียวกับตารางรหัส เป็นสรุปของวัน ไม่ใช่สภาพเดียวกันตลอดวัน |
| พยากรณ์ 8 วัน | `forecast_days=8` | วันนี้และวันถัดไป รวม 8 วัน |

การเลือกวันเปลี่ยนข้อมูลกราฟ ไม่ได้เปลี่ยนการ์ด “สภาพอากาศปัจจุบัน” ให้เป็นของวันอนาคต; ไอคอนรายวันใช้รูปแบบกลางวัน

## 6. การแสดงผลและข้อผิดพลาด

- แสดงเวลาเป็น UTC+7 และแยกเวลาข้อมูลออกจากเวลาดึงข้อมูล
- อุณหภูมิและเปอร์เซ็นต์ปัดแสดงเป็นจำนวนเต็ม; ความเร็วลมและ tooltip ใช้ทศนิยมไม่เกิน 1 ตำแหน่ง
- สีเส้นกราฟเป็นสีแยกประเภทข้อมูล ไม่ใช่ระดับอันตราย: อุณหภูมิ `#A87912`, โอกาสฝน `#287CAD`, ลม `#067668`
- ค่าตัวเลขที่หายแสดง `—` และกราฟเว้นช่วง ไม่แทนด้วย 0
- แคช 15 นาที, ข้อมูลเก่าใช้ได้ไม่เกิน 60 นาทีพร้อมป้ายเตือน, หากไม่มีข้อมูลให้ลองใหม่ ตาม [Spec คุณภาพอากาศ](weather-air-quality-spec.md)

## 7. Acceptance criteria

1. รหัส 61 / 63 / 65 แสดงฝนเล็กน้อย / ฝนปานกลาง / ฝนหนักตามลำดับ
2. รหัส 95 แสดงฝนฟ้าคะนอง แม้เปอร์เซ็นต์ฝนไม่ได้เป็น 100
3. รหัส 0 กลางคืนแสดง 🌙 ไม่แสดง ☀️; รหัส 2 กลางคืนแสดง ☁️
4. รหัส 3 และโอกาสฝน 73% ยังคงสถานะ “มีเมฆมาก”
5. อุณหภูมิ 36°C ในโค้ดปัจจุบันไม่สร้างสถานะ “อากาศร้อน” เอง
6. รหัสไม่รองรับแสดง “ไม่มีข้อมูล”; อุณหภูมิหายแสดง `—` ไม่ใช่ 0°C
7. เลือกวันพรุ่งนี้แล้วกราฟเปลี่ยนวัน แต่การ์ดปัจจุบันยังคงแสดงข้อมูลปัจจุบัน
8. เมื่อพัฒนาเกณฑ์ร้อนในอนาคต ต้องเพิ่มการทดสอบ 34.9, 35.0, 39.9, 40.0°C และกรณีไม่มีอุณหภูมิสูงสุดประจำวัน
